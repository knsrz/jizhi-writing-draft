Core Features

围绕办公长文的完整闭环

01

写作计划可编辑

先生成结构化写作计划，再由用户确认或调整，避免长文直接生成带来的跑题和失控。

02

本地知识库支撑

解析 PDF、DOCX、TXT、Markdown，本地切片、向量化和检索，让资料成为写作依据。

03

分段生成与子 Agent

按章节起草，并在每段完成后进行事实校正和语言润色，降低长文质量漂移。

04

多模型自配置

支持 OpenAI、Gemini、DeepSeek、阿里百炼、SiliconFlow、OpenRouter、Ollama 等兼容接口。

Workflow

从资料到交付的一条写作流水线

  1. 输入需求

    填写主题、文体、风格、字数和知识库范围。

  2. 确认规划

    查看 AI 生成的大纲，按业务判断调整结构。

  3. 分段写作

    逐章生成正文，并持续显示当前进度。

  4. 校正润色

    结合资料校正事实，再按目标文风统一表达。

  5. 导出文档

    保存历史版本，导出 Markdown 或 DOCX。

Architecture

Electron + React 的本地桌面架构

Desktop

Electron 主进程负责 IPC、SQLite、文件导入导出和安全存储，Renderer 提供写作工作台。

Agent

规划、写作、事实校正、润色和进度回调由独立 package 编排，便于测试和复用。

Knowledge

本地解析、切片、embedding、LanceDB 检索，每个知识库独立存储，减少资料污染。

AI Providers

写作模型和嵌入模型分离配置，API Key 进入系统安全存储，不写入明文数据库。
